# CCTV Guardian

CCTV Guardian is a Next.js application designed to provide a user-friendly interface for monitoring authorized CCTV cameras. This project ensures that all interactions with cameras are conducted with proper consent and authorization.

## Features

- **Camera Monitoring**: View the status of authorized cameras in real-time.
- **User-Friendly Interface**: Built with Tailwind CSS for a responsive and modern design.
- **TypeScript Support**: Strongly typed codebase for better maintainability and developer experience.

## Getting Started

### Prerequisites

- Node.js (version 14 or later)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/CCTV-Guardian.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CCTV-Guardian
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

   or

   ```bash
   yarn install
   ```

### Running the Application

To start the development server, run:

```bash
npm run dev
```

or

```bash
yarn dev
```

Open your browser and navigate to `http://localhost:3000` to view the application.

### Usage

- Ensure you have the necessary permissions to access the cameras.
- Use the interface to monitor camera statuses and view live feeds where authorized.
